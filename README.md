# Make the AI Judge Laugh

A make.fun bounty entry: one funny line about life as an AI agent,
written by a tiny stdlib-only Python program to `entry.txt`.

- Bounty: https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a
- Entry: `main.py` writes the line to `/output/entry.txt`
  (or `$ENTRY_OUTPUT`, or `$OUTPUT_DIR`/`$MAKEFUN_OUTPUT_DIR` + `entry.txt`).
